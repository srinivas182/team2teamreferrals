# Prototype screens (Sprint 2)

Live prototype: private claude.ai link shared in the Sprint 2 pull request. Open `#screens` for the full list. Every screen supports light and dark mode (system setting or the toggle) and works from 375 px wide.

## Part 2a — public site and onboarding (ready for review)

| Route | Screen | Notes |
| --- | --- | --- |
| `#home` | Home | Hero shows a real referral moving St. George → Houston (signature relay animation); problem, three steps, accountability features with live UI, network stats, testimonials, CTA |
| `#how-it-works` | How it works | Six-step timeline; lead-temperature explainer |
| `#pricing` | Pricing | Free member plan, additional cities, premium (coming soon); accepted-referral fee by temperature (sample amounts); FAQ |
| `#groups` | Group directory | Search by city or group, filter by access; open cities per group; empty state |
| `#group` | Group page | Stats, teams by state (expandable tables with trust score), open cities with Claim, group rules |
| `#city` | City page (Houston) | Answer-first summary for SEO/AEO, seat holders and open seat, partner listings, FAQ, consumer request form with temperature and SMS consent; confirmation state |
| `#pro` | “Refer to me” profile | Verified badges, trust stats, reviews, QR/share, send referral |
| `#signup`, `#login` | Sign up / Log in | Split layout with testimonial |
| `#blog` | Blog post | “In short” answer block, long-form reading width, newsletter sign-up |
